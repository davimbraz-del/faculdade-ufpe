# AFEGH Distribuidora — site institucional

Landing page da AFEGH Distribuidora, distribuidora de medicamentos para farmácias locais,
com destaque para as novidades: dermocosméticos e suplementos vitamínicos.

Site estático (HTML + CSS + JS puro). Para ver, abra o `index.html` no navegador.

## Estrutura
- `index.html` — página (topo, hero, faixa de novidade, sobre, produtos, novidades, diferenciais, como funciona, depoimentos, dúvidas, contato, rodapé)
- `css/style.css` — estilos (cores roxo/verde-limão da logo)
- `js/main.js` — menu mobile, animações, máscara de CNPJ e envio do formulário pelo WhatsApp
- `assets/logo.jpg` — logo
